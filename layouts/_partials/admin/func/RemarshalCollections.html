{{/* RemarshalCollections ==================== Same collections as `admin/collections/index.yml`, in the order of `admin/func/GetCollections.html`, but emitted as block YAML, with `transform.Remarshal` applied to **each collection separately**. Options ------- The config of each CMS asks for what differs, so nothing here names a CMS: - `key`: the key of the list, `collections` by default (`content` for Pages CMS) - `dividers`: a `divider: true` item between two groups of collections (Sveltia CMS). Decap, Netlify and Static CMS would reject an item without a name, so they get the order alone. A divider goes through the same remarshal as a collection, so it comes out with the same indentation. A CMS whose keys are not those of Decap CMS converts each collection in `admin/cms/{cms}/collection/convert.yml`, called before the remarshal while the collection is still flow text. Why not remarshal the whole list at once ---------------------------------------- Hugo guards its YAML decoder against the Billion Laughs attack (`parser/metadecoders.validateAliasLimitForCollections`). That guard counts map/slice nodes by the address of a temporary variable instead of the address of the collection itself, so the counter is shared between unrelated nodes and a large alias-free document trips it just as an aliased one would: error calling Remarshal: too many YAML aliases for non-scalar nodes Above 10 KB the budget is 10000, and a full admin config (every collection carrying the whole `blocks` field) blows past it. Remarshalling one collection at a time keeps each call far below the budget — the counter is reset on every call — and the concatenated collections are the same document the single call used to produce. Usage ----- {{ partial "admin/func/RemarshalCollections.html" . }} {{ partial "admin/func/RemarshalCollections.html" (dict "dividers" true) }} {{ partial "admin/func/RemarshalCollections.html" (dict "key" "content") }} Input : page context, or a dict of options Output : string — the key followed by one block YAML item per collection */}} {{- $options := cond (reflect.IsMap .) . dict -}} {{- $key := $options.key | default "collections" -}} {{- $dividers := $options.dividers | default false -}} {{- $convert := print "admin/cms/" (site.Params.admin.cms | default "decapcms") "/collection/convert.yml" -}} {{- $converts := templates.Exists (printf "_partials/%s" $convert) -}} {{/* Raw (flow style) items, group after group */}} {{- $items := slice -}} {{- range $index, $group := partial "admin/func/GetCollections.html" . -}} {{- if and $dividers (gt $index 0) -}} {{- $items = $items | append "{ divider: true }" -}} {{- end -}} {{- range $group.collections -}} {{- $item := partial "admin/collections/collection.yml" . -}} {{- if $converts -}} {{- $item = partial $convert $item -}} {{- end -}} {{/* A collection that writes nothing, such as a files collection with no file, is left out: it would come back as an empty list */}} {{- if strings.TrimSpace $item -}} {{- $items = $items | append $item -}} {{- end -}} {{- end -}} {{- end -}} {{- $collections := slice -}} {{- range $items -}} {{/* Keep the `collections: [...]` wrapper: it is what makes Hugo detect the input as YAML (a bare `{...}` is read as JSON), and it makes the remarshal'd output a ready-to-use block sequence item. */}} {{- $raw := printf "%s: [%s]" $key . -}} {{- $yaml := partial "admin/func/RemarshalYaml.html" $raw | strings.TrimSpace -}} {{- with $yaml -}} {{- $collections = $collections | append (. | strings.TrimPrefix (print $key ":") | strings.TrimPrefix "\n") -}} {{- end -}} {{- end -}} {{/* Returned, never printed: this is an `.html` template, so writing the YAML through an output action here would HTML-escape quotes and ampersands. */}} {{- return printf "%s:\n%s\n" $key (delimit $collections "\n") -}}
