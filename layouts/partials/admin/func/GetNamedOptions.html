{{/* Partial to get the options of a select whose values are ISO codes — languages, countries — listed by this module (func/GetLanguageCodes.html, func/GetCountryCodes.html): the codes sorted by their name in the language of the admin, and the table of those names the select labels them with (see widgets/select.js, label_options). A site may narrow the codes of a field, see GetOptions.html. The names come from the theme, from the CLDR (func/GetLanguageName.html, func/GetCountryName.html of hugolify-theme). Without it, a code is its own name: the select keeps its options, which Sveltia CMS requires, and a hugolify-admin-names warning says so — silenced with ignoreLogs on a site without the theme. The same goes while hugo server rebuilds after a module is added, where templates.Exists may answer false (reported with Hugo 0.158). - field (string or map) raw context of the field, see GetOptions.html - codes (string) the partial of this module listing the codes, e.g. "admin/func/GetCountryCodes.html" - name (string) the theme partial naming a code, e.g. "func/GetCountryName.html" Returns a map - options (slice) the codes, sorted by name - labels (map) the name of each code, keyed the way select.js looks an option up: dashes turned into underscores */}} {{- $codes := partial .codes -}} {{- $codes = partial "admin/func/GetOptions.html" (dict "field" .field "options" $codes) -}} {{- $naming := templates.Exists (printf "_partials/%s" .name) -}} {{- if not $naming -}} {{- warnidf "hugolify-admin-names" "The CMS shows codes instead of names: %q, from hugolify-theme, was not found" .name -}} {{- end -}} {{- $named := slice -}} {{- $labels := dict -}} {{- range $codes -}} {{- $name := . -}} {{- if $naming -}}{{- $name = partial $.name . -}}{{- end -}} {{- $named = $named | append (dict "code" . "name" $name) -}} {{- $labels = merge $labels (dict (replace . "-" "_") $name) -}} {{- end -}} {{- $options := slice -}} {{- range sort $named "name" -}} {{- $options = $options | append .code -}} {{- end -}} {{- return (dict "options" $options "labels" $labels) -}}
